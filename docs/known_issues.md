# 已知问题与限制

1. ARMCC5 Rebuild、RVDS汇编链接、Code/RO/RW/ZI、下载及实物均NOT_RUN/NOT_VERIFIED。Clang C对象检查不能替代这些门禁，也未生成新Keil AXF。
2. MCU实物、晶振、Flash容量、OLED控制器/地址、磁力计型号未确认。保持C8配置，未移植RCT6/F4。
3. C8 RAM余量较小。10KiB FreeRTOS heap含所有任务栈/队列；需Keil map和运行高水位才能放行。不得根据旧map或Clang未链接对象推断完整固件Flash一定装得下。
4. 默认历史区只读，真实保存关闭。隔离写后端要求独立已批准区域、足够物理容量及预擦好的空间，且只有128个检查点槽；满时安全失败，无自动擦除/磨损均衡。旧EEPROM和旧Flash索引不迁移写入。
5. 历史无CRC，只能检查格式、页标记和范围，不能恢复原格式未保存的南西方向。没有真实历史dump；golden是明确标注的合成样本。
6. 恢复只读校验后显式请求；不自动推断断电期间骑行距离，不自动续写旧历史。STOP失败可重试，队列/缓存满时新样本会被明确拒绝和计数；不是无限可靠缓冲。
7. 网络默认关闭；AT序列来源于旧工程，尚未和实际EC600N固件/运营商/服务器联调。固定JSON上限2048B、16步、144token、12层，超过则拒绝，须确认真实云端路线规模。
8. 导航没有地图匹配；磁力计未确认时剩余距离仅按有效GPS速度积分估算。确认HMC后的原始方向未做新校准/倾斜补偿，不能声称导航精度。
9. I²C超时为有界短轮询而非精密us定时；需要实测上拉、SCL频率和设备电平。缺屏/传感器失败路径已host验证，实际总线波形未测。
10. 未验证60min运行、30min实物断网及20次实物断电。host的30min时间输入/20次RAM恢复扫描不能替代它们。
11. 普通栈/堆故障会锁存并停机以便调试，未默认开启硬件看门狗或自动复位。不能声称已验证所有故障自动恢复。
12. .git写入受到本环境限制，本轮使用SHA-256完整归档和文本diff追溯，不声称已创建commit。
